# 结构空白字段提醒协议

> 2026-07-25 Kevin 确认
> Kevin 要求：如果这些字段他没填，晚间复盘和 WR 创建时要提醒他。

## 新增字段清单

| 位置 | 字段 | 周期 | 输出 |
|------|------|------|------|
| `## 🔆学习日志` | 今日输入（读书__min / 文章__篇） | 每日 | 晚间 cron 提醒 |
| `## 🔆每日思考` | 今日小赢： | 每日 | 晚间 cron 提醒 |
| `## 🔆每日思考` | 关键决策记录： | 每日 | 晚间 cron 提醒 |
| WR `[F] 家庭温度` | 🟢🟡🔴 + 记一笔 | 每周 | WR cron 提醒 |
| WR 上周复盘 | 🏆 本周小赢 3件事 | 每周 | WR cron 提醒 |

## 提醒规则

### 晚间复盘 cron（22:00）

在推送末尾附加一行——**不催填，只说事实，不要求当场补**：

```
📝 今日输入未记
🏆 今日小赢/决策记录未记
```

条件：
- 日记文件存在（非空窗日）
- 检查 `## 🔆学习日志` 首行是否为「今日输入：（读书__min / 文章__篇）」占位符 → 是则未记
- 检查 `## 🔆每日思考` 首行是否为「今日小赢：」占位符 → 是则未记
- 两字段独立检查，独立输出

### WR 创建 cron（周一）

在简报末尾附加：

```
👨‍👩‍👧‍👧 上周家庭温度未记
🏆 上周小赢未记
```

条件：
- WR 文件 `[F] 家庭温度` 区仍为占位符 → 未记
- WR 上周复盘 `🏆 本周小赢` 区仍为占位符 → 未记

## 不触发场景

- 日记文件不存在（节假日/空窗日） → 不提醒
- GTD 区为空但仅有 `🌑 空窗日` → 不提醒（已标记空窗状态）
- Kevin 当日已填了部分字段 → 只提醒未填的，已填的不提
