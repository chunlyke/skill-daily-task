# 日间任务交互：全量清单展示（2026-06-06 Kevin 纠正）

## 问题现象

Kevin 问「今天有哪些待办」时，我只回复了 Top 5。
Kevin 纠正：「我一天的工作不仅仅只有 TOP 5」

## 根因

把 Top 5 当成了全天唯一任务视图。Top 5 是优先级标记，不是执行边界。

## 正确做法

1. **用户问今天有什么任务 → 展示 Phase 1 全量已选清单**
2. Top 5 用 ⭐ 标记区分，但不只展示 Top 5
3. 已完成的任务打 ✅ 标记，未完成的保留
4. 用户说「我知道就行了」→ 立即停止追问

## 展示对比

**✅ 正确：**
```
📋 今日待办总览
1. ⭐Top 修改对外合作PPT
2. ⭐Top 还银行信用贷 ✅
3. 跟进林晓春律师
4. ⭐Top 准备睿睿上学材料
5. 联系杜紫立
6. 手机套餐变更
```

**❌ 错误（被Kevin纠正）：**
```
📋 今日Top 5
1. 修改PPT — 推进了吗？  ← 只展示Top 5
2. 还贷款 — 还了吗？     ← 且用追问语气
```
