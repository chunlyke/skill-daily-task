# 习惯追踪模式（Habit Tracking Pattern）

## 背景

Kevin 有重复性的睡前/晨间习惯（如「睡前踢屁股」遵魏主任要求）。这些不是单次任务，而是每日打卡项。

## 工作流

当 Kevin 在对话中提及一个新的重复性习惯时：

1. **识别** — 判断是不是重复性习惯（关键词：以后/每天/每晚/睡前/醒来/遵照XX要求）
2. **写入日记** — 添加到当日日记的 `## END-OF-DAY CHECKLIST` 区域，作为每晚打卡项
3. **记入记忆** — 保存到 memory 中，实现跨日记持久化
4. **每日自动继承** — 后续每日日记模板生成时，从记忆读取习惯自动插入 END-OF-DAY CHECKLIST

## 习惯在日记中的格式

```
## END-OF-DAY CHECKLIST（晚上啦）
- [ ] **睡前踢屁股** — 魏主任要求，睡前必做
- [ ] GTD（回顾今天的任务是否完成）
- [ ] review bookmarks（书签）
- [ ] 检查滴答清单
- [ ] 整理今天的日志
```

## 关键规则

- 习惯放在 END-OF-DAY CHECKLIST 首位，突出显示（加粗）
- 附上简短来源说明（如"魏主任要求"）
- 不是单次任务，不写入 GTD & Top 5 Tasks
- 记忆保持精简，只存习惯名称+来源+放置位置
- 当 Kevin 说"不需要这个习惯了"→从记忆和日记模板中移除

## 与晨间cron的关系

晨间日记创建cron（obsidian-journal skill）在生成当日日记模板时，应从记忆读取活跃习惯列表，自动插入 END-OF-DAY CHECKLIST。

## 示例

Kevin: "我以后睡觉之前要做一些动作，遵照魏主任的要求，这个习惯叫做睡前踢屁股"
→ 动作：写入当日日记 END-OF-DAY CHECKLIST + 保存到 memory
→ 结果：每晚打卡，每日日记自动继承
